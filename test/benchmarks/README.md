# Pebbling benchmark suite

Persistent, deterministic benchmark XAGs for the sequence-driven pipeline —
generated by `gen_bench.cpp`, stored under `data/`, described by
`data/bench_manifest.json`.

**Why not RandomXAG?** Uniform random pairing collapses under mockturtle's
structural hashing (a requested 100-AND graph folds to a handful of gates).
`gen_bench` builds *chain-structured* graphs — every gate pairs with the
newest node, so no pair can hash-merge and requested size == actual size
(checked hard; generation fails on any collapse).

## Regenerate / verify

```bash
docker build -t xagtdep .          # once, from the repo root
docker run --rm -v "$PWD/test/benchmarks":/bench xagtdep bash /bench/build_and_run.sh
```

Deterministic inside the image (fixed seeds; random-XAG reproducibility
caveats don't apply to the stored structure dumps, which are the canonical
graphs).

## Contents (9 cases)

| Tier | Cases | What it proves |
|---|---|---|
| `data/verified/` | 3 std (9–10 gates, 4–5 PIs) + 1 **hard** | Strict statevector+QCEC lane: **11/11 circuits equivalent** on last run. The hard case (both-fanins-computed ANDs — the shape Algorithm 1/2's DFS errors on) is QCEC-proven for **pebbling**, cross-checked against **Current**. |
| `data/big/` | 40 / 100 / 200 / 400-gate std + 80-gate hard | Real scale: synthesis + the V1–V7 validator complete instantly; metrics stored. Pebbling uses ~25% fewer qubits than Existing/Proposed (e.g. 413 vs 551 at 400 gates), T-count parity with Proposed at scale. Beyond simulators — stored for future verification tooling. |

Per case: `xag_<i>_<method>.json` (gate lists), `xag_<i>_structure.json`
(the canonical graph: fanins + complements — what David's solver consumes),
`xag_<i>_bennett_sequence.json` (the Bennett schedule for that graph),
`xag_<i>_meta.json` (truth table + per-method metrics).

## Notes / limitations

- **Current (Toffoli) is excluded from std cases**: its cone duplication is
  exponential on deep chains (40 chained gates → 450k gates, 100 → OOM).
  It is included on the small hard case, where it is the only independent
  cross-check for pebbling. Equivalence for std cases is per-method against
  the truth-table oracle, so nothing is lost.
- The verified tier is sized so every method stays ≤ ~17 qubits — the
  brute-force statevector lane is 2^qubits per input row (21-qubit files
  take hours).
- Big-tier equivalence is out of reach for simulators; those cases are the
  standing work-list for future partial/structural verification.
- The DFS methods legitimately cannot synthesize hard-flavor graphs (their
  documented error case) — manifests list which methods each case carries.
